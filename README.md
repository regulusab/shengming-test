# 生命之眼・個人洞察與人生方向報告（測試版）

網址：https://regulusab.github.io/shengming-test/

輸入出生資料，在瀏覽器內排盤、產生報告，並可下載 PDF 與 Word。所有計算都在瀏覽器完成，資料不會上傳。

- 排盤口徑：依出生地鐘錶上記錄的時間排盤；八字與河洛理數 0:00 換日，紫微斗數 23:00 換日；東經 70° 以西日柱加一天（八字與紫微日柱皆同）。
- 紫微斗數與河洛理數的農曆（使用者 2026-11-19 裁定）：以出生地經度地方時（經度×4 分鐘；當地夏令期間再加夏令）的日月合朔定初一，再算出生日是初幾；月序、閏月、年份依中國農曆（同一次合朔開始的月）。東經 70° 以西紫微只有日柱干支加一天，農曆日不加。合朔時刻 1899–2101 用 DE440s 預算表。
- 內建範例皆為虛構生辰，非真實人物。
